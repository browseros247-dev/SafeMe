Accessibility Protection

Keeps SafeMe and selected apps' Accessibility Services enabled and running.

Accessibility Protection
Watch SafeMe and selected services — restore them if disabled or stopped.
Auto-restore permission
Notifications only

Not granted — SafeMe can only notify you when a protected service is disabled. One-time ADB setup enables auto-restore.

1. Connect your phone to a computer and enable USB debugging.
2. Run this command from a terminal:
adb shell pm grant com.safeme.app android.permission.WRITE_SECURE_SETTINGS
Auto-restore needs a one-time WRITE_SECURE_SETTINGS grant via ADB. Services you don't select are never touched. Turn the toggle off to stop restoring.
